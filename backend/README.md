# Second Mind

### A Cognitive AI System for Memory, Reasoning and Knowledge Discovery

## Overview

Second Mind is an experimental AI system designed to explore persistent memory, multi-agent collaboration, reasoning and autonomous knowledge discovery.

## Core Features

- Persistent memory management
- Multiple independent AI agents
- Agent-to-agent communication
- Research and reasoning workflows
- Pattern discovery
- Hypothesis generation and verification
- Knowledge discovery

## AI Agents

**Research Agent (ID: 1)**
- Manages research information.
- Stores research findings.
- Communicates with other agents.

**Reasoning Agent (ID: 2)**
- Receives research findings.
- Generates structured analysis.
- Produces observations and conclusions.
- Sends responses to the Research Agent.

## Technology Stack

- Python
- FastAPI
- SQLAlchemy
- SQLite
- REST API
- Swagger UI
